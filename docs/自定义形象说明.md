# keepBoard 自定义形象使用说明

从 v0.4.0 开始，keepBoard 支持上传你自己的图片作为桌面宠物。本文档介绍功能用法、工作原理与常见问题。

## 一、如何使用

1. **右键点击宠物**，不透明度会循环切换（100 → 75 → 50 → 25），这不是主题入口
2. 打开完整菜单的两种方式：
   - **系统托盘图标** → 右键 → `🎨 主题` → 选择 `🐾 自定义形象`
   - 或右键宠物打开 `⚙ 设置面板` → 找到「🐾 自定义形象」区域
3. 点击 **`📁 上传图片…`**，选择一张你喜欢的图片
4. 上传成功后自动切换到自定义形象；点击 **`↺ 恢复默认`** 可随时回到内置主题

> 提示：也可以在托盘菜单中直接选择其他 12 款内置像素主题。

## 二、支持的格式

| 格式 | 支持 | 备注 |
|------|------|------|
| PNG | ✅ 推荐 | 建议透明背景 |
| JPG / JPEG | ✅ | 无透明通道，会带底色 |
| WebP | ✅ | |
| BMP | ✅ | |
| GIF | ⚠️ 部分支持 | 仅显示第一帧（静态），不会播放帧动画 |

- 图片会**等比例缩放**到合适大小显示，建议尺寸 ≤ 256×256
- 透明背景 PNG 效果最佳（配合像素级点击穿透，只有图案本身可以点选）

## 三、动画效果说明

上传的是静态图片，keepBoard 会用程序为它生成整套"活起来"的动作，与其他主题一致：

| 事件 | 动画 |
|------|------|
| 全局键盘输入（任意程序） | 张嘴咬合（挤压变形）+ 上身抬起 |
| 鼠标点击（任意位置） | 眨眼式浮动 |
| 连续快速打字 | 狂暴模式：抖动 + 高频咬合 |
| 待机 | 悬浮呼吸 + 轻微摇摆 |

## 四、文件存储位置

```
%APPDATA%\keepboard\customPet.png   （扩展名随上传格式变化）
```

- 上传时旧的自定义文件会被自动替换
- 手动删除该文件 = 恢复默认主题
- 也可在设置面板点击「📂 数据目录」快速打开所在文件夹

## 五、常见问题

**Q：为什么我的 GIF 不动？**
当前版本仅取 GIF 第一帧渲染（动画由程序统一驱动以保证风格统一）。帧动画支持在计划中。

**Q：图片太大了怎么办？**
无需处理，会自动等比缩放；但过大的图片会增加内存占用，建议预先缩小。

**Q：上传后想换回食人花？**
托盘菜单 → 🎨 主题 → 🌱 食人花。你的自定义图片仍会保留，随时可切回 🐾。

**Q：透明度在哪里调？**
右键宠物循环切换四档（100/75/50/25），或在托盘菜单 → 🌗 不透明度 中精确选择。
